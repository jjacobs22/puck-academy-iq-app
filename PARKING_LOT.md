## Visual Multiple Choice for Scenarios

**Date parked:** Jan 28, 2025

**The idea:** Instead of showing a static diagram while users consider answer options, show each option as a distinct visual. User sees 4 stance images side-by-side, taps the one they think is correct.

**Why it might be better:**
- Lets users actually *see* the differences between options
- More engaging than text labels with a static illustration
- Teaches through comparison, not just testing

**Why it's parked:**
- Too early to know if engagement is the real problem
- Would require creating multiple visual assets per question
- Want more signal on retention first

**To revisit when:**
- We have data on whether users come back
- Content quality emerges as a clear issue

## Daily SMS / Push Habit Model

**Date parked:** Jan 28, 2025

**The idea:** Instead of users coming to the app, push one question per day via SMS. Track streaks, reward milestones with trophies/badges in a trophy case.

**Why it might be better:**
- Removes friction—question comes to you
- The text itself is the reminder
- Streak mechanics could drive retention

**Why it's parked:**
- Big architectural shift (needs backend, database, SMS service, user accounts)
- Don't have enough data yet to know if this solves a real problem
- Could test the concept manually first (personal texts, group chat pings)

**To revisit when:**
- Manual nudge tests show that reminders actually drive return usage
- Clear signal that delivery model is the bottleneck, not content
